# CLI Interface Contract: Multi-Persona Panels

**Feature**: 003-multi-persona-panels
**Date**: 2026-01-25

## Overview

This document defines the CLI interface contract for multi-persona panel research commands. These commands extend the existing `research-cli` tool from Phases 0 and 1.

---

## Command Structure

```
research-cli
├── persona                    # (Phase 0) Persona management
│   ├── list
│   ├── show
│   ├── validate
│   └── prompt
├── research                   # (Phase 1 + Phase 2)
│   ├── single                 # (Phase 1) Single persona session
│   └── panel                  # (Phase 2) NEW - Panel commands
│       ├── run                # Execute panel research
│       ├── list               # List available panels
│       ├── show               # Show panel details
│       ├── create             # Create custom panel
│       └── delete             # Delete custom panel
└── init                       # (Phase 0) Initialize project
```

## Panel Commands

### `research panel run`

Execute a panel research session.

**Usage**:
```bash
research-cli research panel run --panel=<panel-id> --question="<question>" [options]
```

**Arguments**:

| Argument | Type | Required | Default | Description |
|----------|------|----------|---------|-------------|
| `--panel`, `-p` | string | Yes | - | Panel ID (pre-built or custom) |
| `--question`, `-q` | string | Yes | - | Research question (max 2000 chars) |
| `--format`, `-f` | choice | No | `text` | Output format: `text`, `json` |
| `--output`, `-o` | path | No | - | Export JSON data to file |
| `--report`, `-r` | path | No | - | Generate Markdown report |
| `--quiet` | flag | No | - | Suppress progress display |
| `--timeout` | int | No | 120 | Per-persona timeout in seconds |

### `research panel create`

Create a custom panel.

**Usage**:
```bash
research-cli research panel create --name=<name> --personas=<id1,id2,...> [options]
```

**Arguments**:

| Argument | Type | Required | Default | Description |
|----------|------|----------|---------|-------------|
| `--name`, `-n` | string | Yes | - | Panel ID (slug format) |
| `--personas`, `-p` | string | Yes | - | Comma-separated persona IDs |
| `--description`, `-d` | string | No | - | Panel description |

**Validation**:
- Name must be unique (not conflict with pre-built panels)
- Name must be slug format (lowercase, hyphens only)
- All persona IDs must exist in the library
- Minimum 2 personas, maximum 50

**Output**:
```
✓ Created custom panel: my-test-panel

  Personas: tech-early-adopter, skeptical-late-adopter, busy-professional
  Saved to: panels/custom/my-test-panel.yaml

  Use with: research-cli research panel run --panel=my-test-panel --question="..."
```

**Errors**:
```
✗ Error: Invalid persona IDs: [nonexistent-persona]

  Available personas:
  - tech-early-adopter
  - skeptical-late-adopter
  - busy-professional
  - privacy-conscious-user
  - power-user
```

### `research panel delete`

Delete a custom panel.

**Usage**:
```bash
research-cli research panel delete <panel-id> [options]
```

**Arguments**:

| Argument | Type | Required | Default | Description |
|----------|------|----------|---------|-------------|
| `panel-id` | string | Yes | - | Custom panel ID to delete |
| `--force`, `-f` | flag | No | - | Skip confirmation prompt |

**Validation**:
- Cannot delete pre-built panels
- Panel must exist

**Output**:
```
Are you sure you want to delete panel 'my-test-panel'? [y/N]: y
✓ Deleted panel: my-test-panel
```

## Error Messages

| Error Code | Message | Resolution |
|------------|---------|------------|
| `PANEL_NOT_FOUND` | Panel '{id}' not found | Use `panel list` to see available panels |
| `PERSONA_NOT_FOUND` | Persona '{id}' not found in panel | Verify panel definition has valid persona IDs |
| `QUESTION_TOO_LONG` | Question exceeds 2000 characters | Shorten the question |
| `PANEL_EXECUTION_FAILED` | All personas failed to respond | Check network, retry, or use different panel |
| `PARTIAL_FAILURE` | {n} of {total} personas failed | Results available but incomplete |
| `TIMEOUT` | Panel execution exceeded timeout | Increase --timeout or use smaller panel |
| `CANNOT_DELETE_PREBUILT` | Cannot delete pre-built panel | Only custom panels can be deleted |

## Integration with Phase 1

The panel commands integrate with existing Phase 1 commands:

```bash
# Phase 1: Single persona (unchanged)
research-cli research single --persona=tech-early-adopter --question="..."

# Phase 2: Panel (new)
research-cli research panel run --panel=tech-adopters --question="..."
```

Both commands share:
- Same question format and validation
- Same output formats (text, json)
- Same quality metrics (panel extends with aggregates)
- Same synthetic data disclaimer
